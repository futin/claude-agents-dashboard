A session's pull request, in the chat modal

When a session runs gh pr create, the server spots the PR URL in the transcript, then asks gh pr view --json for its title, state, checks, review and merge status, cached and refreshed on the modal's 3s poll at a slower cadence. Three placements below, each at desktop and phone width, then the dropped everything-version, then every state of the recommended card. Session in every board: this one, building this feature.

Why dropped
  • Merge and re-run are writes to GitHub from the dashboard: a new outbound kind (CLAUDE.md "a third needs a reason") and a token surface on the remote-answer path.
  • main is PR-only and the session that opened the PR is already the one that merges; a second merge button races it.
  • Two places showing the same live state can disagree for a poll tick.
