C

Desktop-app style: one hue, darker = more tokens

Shown to reject

The literal port of the desktop app's grid: a single-hue ramp where a darker cell means more tokens per 1% that day, quantised per model. It is what "a heatmap like Claude Code has" most obviously means, and it is the wrong form for this card: that grid counts how much you used (a magnitude), while this card asks which side of the baseline a day fell on (a polarity).
