## Important findings

### Important | security+bugs | server/index.ts:83 | `serveStatic`'s traversal guard is a bare string prefix, so a sibling directory whose name merely starts with `dist` escapes confinement | `clientDist` has no trailing separator, so `path.join(clientDist, '../dist-secret/x')` → `.../client/dist-secret/x`, which `.startsWith(clientDist)` returns true for

Found independently by both the `security` and `bugs` auditors and merged.

**Failure scenario.** `serveStatic` passes raw `req.url` — never decoded, never normalized —
into a `clean` that only strips leading slashes, then `path.join(clientDist, clean)` collapses
the `..` segments. The guard `!filePath.startsWith(clientDist)` then compares strings with no
separator check, so any path landing in a *sibling* directory whose name begins with `dist`
passes it. A leftover `client/dist-old`, `client/dist.bak`, or `client/dist-ssr` build artifact
would be served to any unauthenticated GET instead of falling back to `index.html`. This server
binds all interfaces, so the listener is not necessarily local-only.

Not exploitable today: no such sibling directory currently exists under `client/`. The fix is a
separator in the comparison (`clientDist + path.sep`), plus decoding `req.url` before joining.

**Verification note (UPHELD).** Verified with node that the join yields the escaping path and
that `.startsWith` returns true; confirmed no upstream code strips `..` or adds a separator.

## Refuted

Three findings were refuted on verification and are excluded from the grades.

**Important | architecture | server/api.ts:1-1153 | God file: 1152 LOC carrying 9+ distinct responsibilities**
REFUTED — `api.ts` is a thin HTTP route-handler layer, not a file where the responsibilities
are implemented. Each of its ~30 exported functions is 12-90 lines, validates input, then
delegates to a dedicated `lib/*` module; the domain logic already lives across 27 lib modules
totalling 7,261 LOC, and `server/index.ts` is a hand-rolled router dispatching to these
handlers by path. The 20 lib imports are evidence that separation of concerns has been done,
not that it is missing. Its size reflects endpoint count.

**Important | architecture | server/lib/pending.ts:251-278, server/lib/plans.ts:166-193 | Wait-store state machine duplicated near-verbatim across three files**
REFUTED as stated — the duplication is real between `pending.ts` and `plans.ts`, but the claim
of a 3-file, 4-function cluster is false: `messages.ts` has no `sweepDecided` at all. Its
analogous release path is `sweepIdle` (line 195), which is materially different — it skips
`headless` entries, calls `backAtDesk()` directly instead of taking an injected `movedOn`
callback, and settles as `'released'` rather than `'dismissed'`. A code comment states the
difference is deliberate.

**Important | tests | server/lib/config.ts:137 | `toBool` has zero test coverage anywhere**
REFUTED — the grep proved only that no test *names* `toBool`, not that it is uncovered.
`test/scan.test.ts:91-101` toggles `SKIP_PROC_SCAN` and asserts `skipProcScan` flips, exercising
the "true" branch and not just the default; `test/transcribe.test.ts:352` and
`test/spawn-endpoint.test.ts:154,162` set `REMOTE_ANSWER=false` and assert on the result. All
reach `toBool` through `loadConfig`.

## Grade calibration — read the F with this caveat

The formula is `10·Critical + 3·Important + 1·Minor` per dimension, and it is sensitive to how
an auditor chooses to split one problem:

- `tests` scored 20 (F) from six upheld findings that are arguably **one** systemic gap —
  `server/api.ts` handlers are untested at the handler layer — itemized by handler group. Filed
  as a single Important it would have scored 3 (B).
- `docs` scored 14 (F) from fourteen instances of **one** defect: wrong `../` hop counts in
  generated guides.

Dedupe merges only findings within ±3 lines of the same file, so it cannot collapse either
cluster. Both F grades are honest counts of real, verified problems; neither means the
dimension is catastrophic. Treat the report card as a map of where to look, and the finding
bodies as the actual verdict.
